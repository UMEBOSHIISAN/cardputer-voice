# Cardputer Voice の演奏

1. Cardputer-Adv をデータ対応USBケーブルでMacにつなぐ。
2. 「歌詞を送る.command」を開き、仮名で歌詞を入力してReturn。例「かえるのうた」。
3. DAWの外部MIDI出力を「Cardputer Voice」、チャンネルを1にする。Ableton LiveではMIDI出力の「Track」を有効にし、MIDIトラックの出力先に選ぶ。「かえるのうた.mid」をMIDIトラックに置くと6音の例を弾ける。
4. 音は本体で合成する。録音には3.5 mm出力をオーディオインターフェースのライン入力へ。音量は受け側で小さめから合わせる。

| MIDI（ch 1） | 動作 |
|---|---|
| ノート36〜96（中央ド=60） | 半音単位の単音演奏。音を重ねると最後に押した音を優先。範囲外は無視。 |
| ベロシティ・CC11 | 音の強さ・演奏中の音量。 |
| ピッチベンド・CC1 | 上下2半音・ビブラートの深さ。 |
| CC20 | 0〜25 あ、26〜51 い、52〜76 う、77〜102 え、103〜127 お。指定しやすい代表値は 0 / 32 / 64 / 96 / 127。 |
| CC21（64以上） | 次の音符から歌詞の先頭。曲頭に置くと繰り返しや途中停止後の再生でも合わせやすい。 |
| CC123 / CC120 | 保持中のMIDI音を解除。 |

1音で1モーラ進み、歌詞の末尾から先頭に戻る。ひらがな・カタカナ、きゃ等の拗音、っ・ん・ーに対応する。漢字は読みを仮名で入力する。一度に96モーラまで。歌詞は電源を切ると消える。歌詞のない状態では選んだ母音で歌う。本体の下段鍵盤と数字キーも使える。

このフォルダで `./voice-midi --demo` はMacから歌詞と表情付きの短い旋律、同一音程で五母音を送る。`./voice-midi --clear` は歌詞を解除する。`./voice-midi "きょうもはれ"` のように直接指定することもできる。

Macからの演奏はDAWのMIDI出力先を指定する。本体鍵盤のMIDI送信およびUSBオーディオは実装していない。
